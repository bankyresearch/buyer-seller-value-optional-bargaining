SCOPE AND CURRENT ACCESS LIMIT
These files support Buyer and seller value from optional automated bargaining
in electronic commerce. They preserve the submitted numerical results. This is
a technical-access revision, not a new experiment or independent replication.

Extract all three Review_Materials ZIP files into ONE new empty directory. Each
ZIP is independently readable; they are not binary split-volume archives. Keep
the internal paths. Run commands from that common directory. Read this guide
before any historical README. Supplementary_Data_1.zip is the unchanged compact
numerical supplement and can be inspected independently.

The package includes original AmazonHistoryPrice and CaSiNo JSON source files,
their notices, cleaned numerical tables, analysis code, ten frozen FQI models,
saved simulation outcomes, summary results and six figure sources. Source files
are byte-checked against the original acquisition manifest. Author-generated
simulations are not observations of customers or field transactions.

CraigslistBargain raw JSON and the 15 derived files listed in SOURCE_OMISSIONS.json
are not redistributed, because the corpus maintainers have not stated a data
licence. Reviewers obtain the exact inputs directly from the maintainers' original
CodaLab endpoints instead:
  python review_support/fetch_craigslist_sources.py --output craigslist_inputs --allow-unverified-tls
The CodaLab TLS certificate expired on 7 October 2026, so integrity is established
by SHA-256, not by the certificate: the script keeps a file only if its checksum
equals the study record in SOURCE_REGISTER.json, and deletes it otherwise. Without
the flag it stops at the certificate error. On 15 October 2026 all three files
downloaded this way matched the recorded checksums (CRAIGSLIST_RECONSTRUCTION_CHECK.json).
The Hugging Face loader is not an alternative copy: it points to the same CodaLab
URLs and transforms the records. Do not substitute another dataset version.

ENVIRONMENT AND SECURITY
CPython 3.12.14 was used. Exact numerical package versions are recorded in
focused_bargaining_20261002/packaging/requirements.txt. Install them in an isolated
environment; no runtime binaries, dependencies, paid APIs or credentials are
included. Optional Word-document authoring is not needed to verify the results.
Joblib files use pickle and can execute code. Verify hashes and inspect code
before loading trusted author-supplied models. CSV inspection requires no model
loading. Use fresh output directories; never replace the canonical results.

FORMULAS AND CODING
See SOURCE_VARIABLES.txt for source fields and transformations. Detailed
simulation and accounting schemas are in the integration/schema.json and
analysis/schema.json files under focused_bargaining_20261002. The following
notation is an executable accounting crosswalk, not a new model specification.

All prices and values below are divided by each product listing price.
v = simulated buyer value; f = assumed seller floor; x = agreed price;
d = agreement indicator; h = attempted rounds; e = 1 if v >= 1, otherwise 0.
q = stipulated opt-in probability; r = stipulated return-to-checkout probability;
cs and cb = separate seller and buyer costs per bargaining round.
Checkout-only seller value S0 = e*(1-f); buyer value B0 = e*(v-1).
Negotiation value Ns = d*(x-f); Nb = d*(v-x), both zero on failure.
Seller increment = q*(Ns-S0+(1-d)*r*S0-cs*h).
Buyer increment = q*(Nb-B0+(1-d)*r*B0-cb*h).
Conversion increment = q*(d-e+(1-d)*r*e).
Joint increment is the sum of seller and buyer increments.
For exogenous uptake q=p. Under value-dependent odds, q=2*p/(1+p) below
listing value, and q=p/(2-p) for checkout-eligible opportunities.
raw_coefficients, weighted and outcome in channel_analysis.py implement these
expressions; route_oracle independently calculates route probabilities and
receipts. Failed-price cells are missing, not zero-price sales.

Average 80 opportunities and the five fixed learned-policy seeds WITHIN each
product, then average the 193 product means. Deterministic rules have seed -1.
The 2,000 product bootstrap resamples use seed 20261002. They are marginal,
exploratory intervals conditional on frozen learners and simulator assumptions.
Do not count millions of policy executions as independent empirical customers.
Negative or above-one algebraic probability boundaries are retained and flagged,
not clipped into feasible probabilities. Undefined ratios remain missing; the
denominator stability flags in analysis/schema.json must accompany interpretation.
